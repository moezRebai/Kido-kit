TeamFlow · distribution

TeamFlow Marketplace

How a pack goes from a pull request to every workstation: Bitbucket Data Center for source and review, Jenkins for validation and build, Artifactory staging and release for storage, and tf-packs on each machine. The Hub (phase 2 and later) only reads and triggers. Companion to 10-marketplace-and-packs.md and 11-hub-and-telemetry.md.
