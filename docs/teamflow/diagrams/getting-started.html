TeamFlow in Six Requests

Type what you want in Kilo Code, in plain language. TeamFlow picks the right skills, asks you questions, and asks you to confirm before every important step. Everything TeamFlow can do comes from packs installed from the company marketplace.

1 · YouDescribe what you want“Add a CSV export”, “explain this file”…
2 · teamflowThe router picks a skillIf unsure, it asks you one question.
3 · SkillsThey work with youQuestions, proposals, and your confirmation at key moments.
router you confirm what you get if needed

What is a skill?

tf-jira/
├── SKILL.md      # the instructions
├── references/   # templates, rules
└── scripts/      # the code
    └── jira.mjs
SKILL.md
What the skill does and how it must work. This is what the coding agent reads.
references/
Spec templates, checklists, team conventions. A team can replace them with its own.
scripts/
Code that must always do exactly the same thing: create a Jira ticket, open a Bitbucket pull request, publish to Confluence.
