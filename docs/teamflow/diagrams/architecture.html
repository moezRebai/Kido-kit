TeamFlow Architecture

Everything is a skill. A router picks the right skill or agent, two spec-driven journeys (solo and team) share one method, and every capability reaches workstations as a versioned pack from the company marketplace. Companion to 02-architecture.md.

The first file found wins. Invariants cannot be overridden: file layout, state.md schema and transitions, human gates, TDD proof, spec-traceability review, integration scripts. Org-enforced packs and agents cannot be disabled.
